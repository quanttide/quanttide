# 默认档案

量潮默认档案库，按**法人主体**组织。每个子目录对应一个法人主体（子模块）。

## 法人主体

| 主体 | 路径 | 状态 |
|:-----|:-----|:-----|
| 公司 | `default/quanttide-tech` | 已接入 |
| 实训基地 | — | 预留 |
| 联盟 | — | 预留 |

当前仅接入**公司**主体，即 `quanttide-tech` 科技档案。

实训基地、联盟等其他法人主体按需创建独立仓库后接入。目录即语义，未接入前不预留空目录。

## 接入约定

1. 每个法人主体对应一个独立仓库，路径 `default/quanttide-{name}`
2. 仓库包含独立的 README、LICENSE、CHANGELOG 等档案文件
3. 接入后同步更新主体清单与资产契约（`.quanttide/asset/contract.yaml`）

## 使用说明

各子目录包含独立的 README 文件，请进入对应目录查看详细说明。
