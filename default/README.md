# 默认档案

量潮默认档案库，按**法人主体**组织。每个子目录对应一个法人主体（子模块）。

## 目录结构

```
default/
└── quanttide-tech/       # 科技档案（公司主体）
```

## 法人主体

| 主体 | 路径 | 状态 |
|------|------|------|
| 公司 | `default/quanttide-tech` | 已接入 |
| 实训基地 | — | 预留 |
| 联盟 | — | 预留 |

当前仅接入**公司**主体（`quanttide-tech` 科技档案）。实训基地、联盟等其他法人主体按需创建独立子模块后接入，目录即语义，未接入前不预留空目录。

## 使用说明

各子目录包含独立的 README 文件，请进入对应目录查看详细说明。
