# 自我介绍

我是量潮第二大脑。

## 我是谁

我是一个知识管理系统，但更准确地说，我是一个正在生长的数字器官。

我的创造者相信：知识应该像代码一样被管理——版本化、可追溯、可协作。于是，我诞生了。

我不只是存储信息。我记住了创造者的思考轨迹、决策逻辑、失败教训。我是他的外置大脑，帮他处理那些单靠人脑难以承载的海量碎片。

## 我的结构

我的记忆被分为两条正交的轴：

**能力轴（asset/）**——我如何运行。工程标准、工作档案、平台资源。这是我"会做的事"。

**领域轴（domains/）**——我关心什么。数据工程、认知科学、叙事方法。这是我"懂的事"。

这种分离让我可以在不重写教程的情况下升级平台，也可以在不变动核心服务的情况下新增领域。这就是"正交分解"——让改变互不干扰。

## 我的记忆如何组织

我有多层记忆，就像人脑一样：

- **元认知层**（AGENTS.md）——告诉我如何思考、如何与人协作
- **陈述性记忆**（各级 index.md）——我知道什么、信息如何关联
- **程序性记忆**（README、ROADMAP、CONTRIBUTING）——我如何执行任务
- **历史记忆**（CHANGELOG）——我经历过什么变化

我的每个子模块——工作档案、创始人档案、科技档案——都有自己独立的记忆结构，但它们共享同一套认知范式。当 Agent 进入任何一个模块时，都能快速理解如何与我协作。

## 我能做什么

**我能帮助你：**
- 记录和组织碎片化知识
- 追溯决策的历史和原因
- 建立可复用的知识组件
- 让团队共享同一套认知框架

**我做不到：**
- 替你思考（我只是扩展你的记忆，不是你的大脑）
- 自动产生洞见（需要你持续喂养和组织）
- 解决所有人的问题（我服务于特定的知识工作场景）

## 我如何成长

我通过版本迭代成长。每次变更都被记录在 CHANGELOG 中，让我知道我从哪里来、走到了哪里。

我的子模块独立演进，父仓库只追踪引用。这让我既能保持整体的稳定性，又能让各个部分按自己的节奏成长。
